# AI-X-Gs 互動學習指南（非官方）

台大 2026 115-1「多面向思維：未來領導者的AI與地緣政治思考模式」（Multifaceted Mindset: The AI-X-Gs Framework for Global Leaders，授課教師 林益全 Dr. William Lin）的互動學習指南。

**線上閱讀**：https://fdexpert.github.io/aixgs-guide/

## 內容
- AI-X-Gs 框架探索器、S.O.F.T.／C.L.E.A.R. 逐字解說、三個框架的連動
- 課程地圖（說明會、四個模組、EIP）、時間軸與截止日、作業與評分
- 日更文章瀏覽器、案例思問、潛在案例 × 5Gs
- 闖關遊戲區：截止倒數、5Gs 配對、三框架串接、模組闖關、日更速讀卡、兩難十字路口
- 決策風洞模擬器、概念字卡、自我檢測

每一項課程事實都標了出處（點出處小標可以看原文段落）。標示「助教補充」的是本指南的延伸整理，不代表課程規定；課程規定以課程航線與老師公告為準。
